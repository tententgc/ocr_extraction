Business rules

Free mode runs extraction only — nothing is checked against master data, arithmetic or prior postings, and nothing can block.

The twenty-six checks that ship with the system encode a generic finance policy. Switch them off if yours is different: the rules you compiled from a prompt still run, and unlike ticking every box this keeps meaning the same thing after a release adds a rule.

Write a rule

Describe a check in your own words. It is compiled once, here — you read it back and try it on documents already processed before it is saved. Most checks become a condition, evaluated after that by plain code and never by a model. A check that needs a lookup and a judgement becomes an agent instead: it keeps a model at validation time, but only to work through the plan you approved, on the documents you scoped it to.

A condition compares fields and runs free on every document. An agent works through a plan with tools — use it when the check needs a lookup and a judgement about what comes back.
