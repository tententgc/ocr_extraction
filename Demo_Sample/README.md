# Demo_Sample — เอกสาร 10 ใบสำหรับเดโม

เอกสารชุดนี้ต่างจาก `real_samples/` ตรงจุดประสงค์

`real_samples/` มี 30 ใบ ไว้ **วัดผล** — มีใบที่กำกวมโดยตั้งใจ เพราะชุดที่มีแต่ข้อง่ายจะรายงานตัวเลขที่ไม่ควรเชื่อ

ชุดนี้มี 10 ใบ (ผ่าน 5 ไม่ผ่าน 5) ไว้ **ดู** — ทุกใบมีคำตอบที่เถียงไม่ได้ และแต่ละใบตกหรือผ่านด้วย**เหตุผลเดียว**ที่ชี้ได้ในประโยคเดียว

> **คำตอบอยู่ในชื่อไฟล์แล้ว** `PASS` = ควรโพสต์อัตโนมัติ · `FAIL` = ควรถูกหยุด — เขียนไว้**ก่อน**ถามระบบ ชุดที่รู้คำตอบหลังรันคือชุดที่ถูกพูดให้เห็นด้วยกับอะไรก็ได้

### ❌ ไม่ผ่าน — ควรถูกหยุด

| # | ไฟล์ | รูปแบบ | ตกเพราะ | ชนิดของความผิด |

**ห้าใบที่ตก ตกคนละกลไก** — สองใบเป็นเอกสารขัดกับตัวเอง (จับได้ด้วยการคำนวณใหม่ ไม่ต้องค้นอะไร) · สองใบเป็นเรื่องที่อ่านเอกสารดีแค่ไหนก็ไม่เจอ (ต้องมีทะเบียน) · หนึ่งใบต้องดึงข้อมูลมาแล้วบวกเทียบก่อนถึงตอบได้ (งานของ agent)

เดโมที่ทุกใบตกด้วยกลไกเดียวกัน สอนว่าระบบมีกลไกเดียว

**ห้าใบที่ผ่าน ก็ไม่ใช่ห้าสำเนาของกันและกัน** — ใบ 03 ผ่าน*เพราะ*ช่องหนึ่งหายไปและนั่นไม่ผิด · ใบ 04 เป็น schema คนละอัน · ใบ 05 คือรูปแบบที่เอกสารจริงมาถึงจริงๆ และเป็นใบเดียวที่ OCR กับขั้นเตรียมภาพต้องออกแรง

**มี PDF · PNG · JPG เพราะมันคนละเส้นทาง** — PDF มี text layer อยู่ในตัว · PNG กับ JPG ไม่มีเลย OCR จึงเป็นสิ่งเดียวที่คั่นระหว่างหน้ากระดาษกับข้อมูล เดโมด้วย PDF ล้วนคือเดโมครึ่งที่ง่าย

## รันในระบบ

```bash
docuflow reset --confirm
docuflow master load Demo_Sample/master
docuflow process Demo_Sample/01_PASS_invoice_clean.pdf
```

หรือรันทีละใบทั้ง 10:

```bash
for f in Demo_Sample/[01][0-9]_*.{pdf,png,jpg}; do [ -e "$f" ] && docuflow process "$f"; done
```

### ⚠ ต้องเช็ค `DISABLED_RULES` ก่อน

`.env` ในเครื่องนี้ปิดกฎไว้บางข้อ และ **สองข้อในนั้นคือข้อที่เดโมใบ 06 กับ 08 พึ่งพา**:

| กฎ | ถ้าปิดไว้ |
|---|---|
| `bank_account_matches_vendor` | **ใบ 06 จะโพสต์ผ่าน** ทั้งที่เลขบัญชีไม่ตรงทะเบียน |
| `po_amount_within_tolerance` | **ใบ 08 จะโพสต์ผ่าน** ทั้งที่วางบิลเกินวงเงิน |

ไม่ใช่บั๊ก — เป็นสิ่งที่ `DISABLED_RULES` มีไว้ทำ แต่ถ้าไม่รู้ก็จะดูเหมือนระบบพัง ตรวจด้วย:

```bash
grep '^DISABLED_RULES' .env
```

ถ้ามีสองชื่อนั้นอยู่ ให้เอาออกก่อนเดโม หรือสั่งทับเฉพาะรอบนั้น:

```bash
DISABLED_RULES="payment_terms_stated,tax_id_belongs_to_this_vendor,vat_rate_expected,currency_matches_vendor_default,tax_id_checksum" docuflow process Demo_Sample/06_FAIL_invoice_bank_account_changed.png
```

## สร้างใหม่

```bash
docuflow demo-set --out Demo_Sample
```

แก้เอกสารที่ `src/docuflow/samples/demo_set.py` ไม่ใช่ที่ไฟล์ในโฟลเดอร์นี้ — build ครั้งถัดไปเขียนทับหมด

`ground_truth.json` เก็บค่าที่ถูกต้องของทุกช่อง พร้อม `reference_text` ซึ่งคือข้อความที่หน้ากระดาษพิมพ์จริงๆ อ่านจาก text layer ของ PDF **ก่อน**ที่มันจะถูกแปลงเป็นรูป — นั่นคือเฉลยที่ OCR ถูกวัดเทียบ และมันแม่นเพราะเอกสารถูกวาดขึ้นที่นี่
